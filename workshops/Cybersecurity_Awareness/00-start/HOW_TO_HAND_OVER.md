# Handing this to Claude

For Claude Code or a coding workspace: extract the ZIP into a project folder. Start Claude in that folder and paste CLAUDE_START_PROMPT.md. Claude should have read/write access to the project and a browser renderer for visual checking.

For a chat interface: attach the ZIP if that interface can extract and inspect files, then paste the start prompt. If it cannot unpack a ZIP, upload the key Markdown/JSON files and prototype HTML, plus the six reference screenshots individually. Do not rely on screenshots alone.

This package authorises a local full build. It does not require deployment or sending messages to participants. Missing customer inputs remain placeholders during implementation. The finished course needs a facilitator's rehearsal and confirmed customer reporting route before delivery.

Keep this package alongside the generated deck. When asking for edits, name the module/slide ID, explain the desired change and ask Claude to update relevant notes, content JSON and validation records together. A change to palette or typography requires new visual baseline screenshots.
