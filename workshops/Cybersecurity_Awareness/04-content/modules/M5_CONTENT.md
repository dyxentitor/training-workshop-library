# M5 content script

## SL42: Mei offers help in chat
Time: 15:05–15:10 (5 minutes). Layout: chat. Evidence: fictional.
Objective: Check claimed IT identity

Screen copy:
- Someone using Mei’s name offers to fix an access problem.

Evidence to create: Workplace chat requests a remote-support session.
Interaction: Reveal display name and request.
Reveal: Verify a support ticket through the established helpdesk.
Facilitator notes: This is a separate scene, not proof the earlier fraud caused an account issue.
Sources: S15

## SL43: Remote access changes the stakes
Time: 15:10–15:16 (6 minutes). Layout: decision. Evidence: fictional.

- Which approved support request does this match?

Facilitator notes: Legitimate remote tools can be abused. No live remote session.

## SL45: A browser problem becomes a repair request

## SL47: Which support request can you proceed with?
Time: 15:35–15:40 (5 minutes). Layout: decision. Evidence: fictional.
Objective: Recognise a legitimate verified support process

Screen copy:
- A ticket you raised appears in the known portal.

Evidence to create: Mei’s identity and session match the independently checked ticket.
Interaction: Choose permitted next step under support policy.
Reveal: Verified support still follows access and data rules.
Facilitator notes: Include this genuine example so learners do not reject all IT help.
Sources: S20


### SL43 explicit decision key
- Accept control because the tool is well known: A legitimate tool can still enable unauthorised access.
- Verify the ticket through the established helpdesk: Check support identity, purpose and authorised access before proceeding. [Preferred]
- Send a login code to prove the account: Do not disclose codes to an unsolicited caller.

### SL47 explicit decision key
- Follow the verified support process: The known ticket confirms context; access and data rules still apply. [Preferred]
- Give unrestricted control and all files: Verified support does not remove access limits.
- Reject all help even for a verified ticket: Approved support can proceed under the normal policy.
