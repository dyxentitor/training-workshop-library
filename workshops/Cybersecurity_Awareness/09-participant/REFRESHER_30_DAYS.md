# Optional 30-day refresher draft

You receive a well-written message from a familiar supplier saying its payment details changed. The signature includes a new phone number for confirmation.

Discuss: which number should you use, what permission is required before updating the record, and whom should you tell if you already paid?

Answer reveal: use the established contact record, follow approval/change procedures, and escalate payment concerns promptly through finance/security and the bank's established route.

Second scenario: a genuine sign-in page asks for a code you received in an unexpected document invitation. Ask whose device/session the code would authorise. Do not enter unsolicited codes; use the known application and report concerns.

This is a reusable draft. No future send or reminder has been scheduled. Source context: S7 and S12.
